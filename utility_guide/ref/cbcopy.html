cbcopy

cbcopy utility for migrating data from Greenplum Database to SynxDB

Synopsis

cbcopy [flags]

Description

General Settings:

--help

Display help information and exit (default: false) --version

Show the application version and exit (default: false) --debug

Enable debug-level log messages for troubleshooting (default: false) --verbose

Enable verbose logging for detailed output (default: false) --quiet

Suppress informational logs; only show warnings and errors (default: false)

Source Database Settings:

--source-host

Hostname or IP address of the source database cluster (default: 127.0.0.1)

--source-port

Port number for the source database connection (default: 5432)

--source-user

Username to connect to the source database (default: gpadmin)

--dbname

Comma-separated list of databases to migrate from the source

--schema

Comma-separated list of schemas to migrate (format: database.schema)

--include-table

Migrate specific tables only (format: database.schema.table, comma-separated)

--include-table-file

Migrate tables listed in a file (one per line: dbname.schema.table)

--exclude-table

Exclude specific tables from migration (comma-separated)

--exclude-table-file

Exclude tables listed in a file (one per line: dbname.schema.table)

Destination Database Settings:

--dest-host

Hostname or IP address of the destination database cluster (default: 127.0.0.1)

--dest-port

Port number for the destination database connection (default: 5432)

--dest-user

Username to connect to the destination database (default: gpadmin)

--dest-dbname

Comma-separated list of target databases in the destination cluster

--dest-schema

Comma-separated list of target schemas in the destination database

--dest-table

New table names for migrated tables (comma-separated)

--dest-table-file

File containing new table names for migration (one per line: dbname.schema.table)

Data Migration Controls:

--full

Migrate the entire data cluster, including all databases, schemas, and tables (default: false)

--data-only

Migrate only the table data; skip metadata like schema definitions (default: false)

--metadata-only

Migrate only metadata (schemas, tables, roles); exclude table data (default: false)

--global-metadata-only

Migrate global metadata (roles, tablespaces) without table data (default: false)

--with-global-metadata

Include global objects (roles, tablespaces) during migration (default: false)

--append

Append data to existing tables in the destination (default: false)

--truncate

Clear (truncate) existing data in destination tables before migration (default: false)

--validate

Validate data consistency after migration (default: true)

Performance Tuning & Parallelism:

--copy-jobs

Maximum number of tables to migrate concurrently (1-512) (default: 4)

--metadata-jobs

Maximum number of concurrent metadata restore tasks (1-512) (default: 2)

--on-segment-threshold

Threshold (row count) for switching to direct coordinator copy mode (default: 1000000)

Advanced Settings:

--owner-mapping-file

File mapping source roles to target roles (format: source_role,dest_role)

--schema-mapping-file

File mapping source schemas to target schemas (format: source_db.schema,dest_db.schema)

--dest-tablespace

Create all migrated objects in the specified tablespace in the destination

--tablespace-mapping-file

File mapping source tablespaces to destination tablespaces (format: source,dest)

--compression

Transfer compressed data instead of uncompressed/plain data (default: false)

Network Settings:

--data-port-range

Port range for data transfer during migration (format: start-end) (default: 1024-65535)
